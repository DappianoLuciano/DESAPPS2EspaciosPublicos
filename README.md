# CityPass+

Repositorio del proyecto CityPass+.

## Estructura

- `espacios-publicos-backend`: backend del modulo Espacios Publicos y Cultura.
- `espacios-publicos-frontend`: carpeta reservada para el frontend que vamos a integrar mas adelante.

## Backend

Para trabajar con el backend:

```bash
cd espacios-publicos-backend
npm install
npm run dev
```

La app queda disponible en:

```txt
http://localhost:3000
```

Healthcheck:

```txt
http://localhost:3000/health
```
